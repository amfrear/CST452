## Project Overview
Medical Journey Log is a caregiver-focused application designed to help families track symptoms, health events, and medical changes for their children.  
Milestone 6 represents the **Final Project Review**, combining all project development, testing, documentation, and presentation materials into one final deliverable.

The application includes:

- Add, edit, delete Children  
- Add, edit, delete Symptoms (per child)  
- View child profiles with full symptom history  
- Validated form inputs  
- Relational MySQL data storage  
- A polished user workflow and consistent UI  

> Authentication is intentionally out of scope, as the application is designed for personal, single-user caregiver use.
