## Project Overview

Medical Journey Log is a caregiver-focused application designed to help families track symptoms, health events, and medical changes for their children.

Milestone 6 represents the **Final Project Review**, combining all project development, testing, documentation, and presentation materials into one complete deliverable.

### ✔️ Application Features
- Add, edit, delete Children  
- Add, edit, delete Symptoms (per child)  
- View child profiles with full symptom history  
- Validated form inputs  
- Relational MySQL data storage  
- Clean Razor Pages architecture  
- User-friendly workflow and consistent UI  

> **Authentication is intentionally out of scope** since this is a personal, single-user caregiver application.
