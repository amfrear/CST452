## 📘 Overview
This repository folder contains the final **Technology Showcase Poster** deliverable for my CST-452 Capstone Project at Grand Canyon University.  
The poster summarizes the design, functionality, and purpose of my application **Medical Journey Log**, a web-based tool that helps families track medical notes, symptoms, and milestones for their children.

---

## 🧩 Project Description
**Medical Journey Log** was developed to simplify the documentation of pediatric medical care by providing caregivers with an organized, private system to log health updates and progress.  
The application was inspired by real-world caregiving challenges and aims to reduce stress while improving communication between family members and healthcare providers.

---

## 🧠 Design Process
The project followed a structured **Software Development Life Cycle (SDLC)**:
1. **Planning** – Defined user needs and project scope.  
2. **Design** – Created architecture diagrams and UI wireframes.  
3. **Implementation** – Built using ASP.NET Razor Pages (C#) with MySQL backend.  
4. **Testing** – Verified all forms, validations, and navigation logic.  
5. **Deployment** – Prepared the final build and documentation for presentation.
